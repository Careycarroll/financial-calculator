▼
🟢 Alpha (α)
Manager Skill / Pure Edge

Did the fund beat expectations? Any return above 0% means it earned extra profit beyond just riding market risk.

🔵 Beta (β)
Volatility Multiplier

1.0 moves exactly with the market. >1.0 means bigger swings (aggressive); <1.0 cushions market drops (defensive).

🟣 Sharpe Ratio
Quality of Returns

Excess return divided by volatility. Scores above 1.0 indicate high-efficiency, smooth long-term compounding.

⚖️ Capture Ratio
Asymmetric Defense

Compares bull-market gains to bear-market drops. The goal is capturing rallies while absorbing fewer crash losses.
